# Pemrograman_Arfan-nabil-ramadhan_Emerald_TLS26
Repositori ini berisi penyelesaian tugas pemrograman dasar TLS 2026 yang terdiri dari dua fase pengerjaan:
Struktur Repositori
Fase 1 Fase1_Logika.pdf
Berisi rancangan logika penyelesaian masalah berupa Pseudocode untuk Problem 1 The Last Astronaut dan Problem 2 Alien-In-The-Middle.
Dilengkapi dengan penjelasan logika minimal 2 paragraf untuk masing-masing problem.

Fase 2 Problem1.cpp & Problem2.cpp
Problem 1 Problem1.cpp: Program berbasis C++ untuk mensimulasikan proses seleksi eliminasi astronot dalam posisi melingkar dengan perubahan aturan nilai K secara dinamis.
Problem 2 Problem2.cpp: Program berbasis C++ untuk mengimplementasikan algoritma enkripsi sandi rahasia berdasarkan nilai pergeseran huruf sebelumnya.
